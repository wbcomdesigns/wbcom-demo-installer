One-click demo content installer for the Reign theme. Import complete demo sites with plugins, content, and settings.

== Description ==

**Reign Theme Demo Installer** is a powerful plugin designed specifically for the Reign WordPress theme. It allows you to quickly import complete demo sites with just a few clicks, including all the necessary plugins, content, customizer settings, and configurations.

= Key Features =

* **One-Click Demo Import**: Import complete demo sites instantly
* **Multiple Demo Variations**: Choose from various pre-built demo sites
* **Automatic Plugin Installation**: Required plugins are installed and activated automatically
* **Content Import**: Posts, pages, menus, widgets, and media files
* **Customizer Settings**: Theme options and customizations
* **BuddyBoss/BuddyPress Ready**: Specialized demos for community sites
* **E-commerce Ready**: WooCommerce and marketplace demos available
* **Learning Management**: LearnDash, LifterLMS, and other LMS demos
* **Secure & Safe**: Built with security best practices

= Available Demo Types =

* **Community Sites**: BuddyBoss Platform and BuddyPress demos
* **E-commerce**: WooCommerce, Dokan, WC Vendors, WCFM Marketplace
* **Learning Management**: LearnDash, LifterLMS, Tutor LMS, Sensei LMS
* **Job Portal**: WP Job Manager integration
* **Directory Listing**: GeoDirectory integration
* **Social Community**: PeepSo integration

= Requirements =

* WordPress 5.0 or higher
* PHP 7.4 or higher
* Reign theme (active)
* Sufficient memory limit (512MB recommended)
* Administrator privileges

= Important Notes =

* This plugin is designed specifically for the Reign theme
* Demo import is recommended for fresh installations only
* Always create a full backup before importing demo content
* Some demos require premium plugins (available separately)

== Installation ==

1. Upload the plugin files to the `/wp-content/plugins/reign-demo-installer` directory, or install the plugin through the WordPress plugins screen directly.
2. Activate the plugin through the 'Plugins' screen in WordPress
3. Make sure the Reign theme is active
4. Navigate to 'Demo Installer' in your WordPress admin menu
5. Select and import your desired demo

== Frequently Asked Questions ==

= Is this plugin free? =

Yes, the plugin itself is completely free. However, some demo sites may require premium plugins that are sold separately.

= Can I use this with other themes? =

This plugin is specifically designed for the Reign theme. While it may work with other themes, optimal results are only guaranteed with Reign.

= Will this overwrite my existing content? =

The demo import process is designed for fresh installations. It may overwrite existing content, so we strongly recommend using it only on new sites or after creating a full backup.

= What if the import fails? =

If an import fails, you can try again or check the plugin's log files for more information. You can also contact our support team for assistance.

= How long does the import process take? =

Import time varies depending on the demo size and your server performance. Most imports complete within 5-15 minutes.

= Can I preview demos before importing? =

Yes, each demo includes a preview link so you can see exactly what the imported site will look like.

= What plugins are included? =

Each demo specifies which plugins are required. The installer will automatically download and activate free plugins from the WordPress repository. Premium plugins need to be purchased separately.

= Is there a limit to how many times I can import? =

No, you can import demos as many times as needed. However, each import will reset your site content.
